# Retained contribution continuity and operation compatibility

This bundled guide is advisory discovery, not an authority grant or execution
prerequisite requiring a source checkout. Read installed help and the owning
service's supported schemas before each operation. The bundle's broad Aegis
compatibility range describes foundation discovery only: capability is
operation-specific. A newer skill archive does not upgrade an older executable,
activate a runtime, qualify a provider or supply a missing adapter.

## Discover the exact installed operation

| Intent | Required installed adapter | If absent |
| --- | --- | --- |
| Select and invoke a contribution | Authenticated manager `/contribute select` and `/contribute run` | unavailable; a Loop definition or ordinary chat is not an adapter |
| Observe or resume retained contribution | Authenticated manager `/contribute status` and `/contribute resume` | unavailable; do not invent CLI commands or open stores |
| Narrow or stop contribution | Authenticated manager `/contribute narrow` and `/contribute stop` | unavailable; login does not grant new scope |
| Retrieve terminal result | `aegis queue result ITEM` for the exact retained Queue item, through the owning service when online | unavailable if installed help or online adapter is missing; checkpoint status is not terminal success |
| Review independent provisioning decision | Existing protected native companion and exact owning-service review/approval protocol | unavailable or blocked on the actual human decision; never approve conversationally |

Check both executable and owning-service capabilities. CLI, HTTP, manager and
Console adapters are not interchangeable. The bundled operation matrix assigns
operation ownership but is structural source coverage, not a runtime capability
probe or release qualification. No minimum-version inference can replace exact
installed help, protocol compatibility and authoritative readback. When unavailable,
stop with that exact missing adapter; never stop the gateway, use a second state
writer, extract credentials or construct a replacement authenticated client.

## Same retained invocation

`/contribute status [issue-url]` and `/contribute resume [issue-url]` discover the
same owner's retained invocation. No reference selects only a unique eligible
invocation; ambiguity is a conflict, never latest-wins. Resume requires fresh
same-owner authentication and original immutable Loop/run/Queue/key references.
It preserves scope, absolute deadline, original attempt, source custody and all
cumulative budgets. Authentication is not provisioning approval, task re-consent,
a new mandate or permission to revive an expired role. Compatible new role epochs
require independently admitted clean sessions; historical roles remain immutable.

Keep source lineage separate from the frozen candidate digest. Unknown native or
remote effects retain custody until the owning service reconciles the exact
original intent. Cancellation records sticky stop before exact-owned shutdown;
process absence or lease expiry alone is not acknowledgement. Never rotate keys,
replace the Agent/Loop/run, reset counters, resend an unknown write or force-push
to evade a held outcome. Use supported readback and report blocked, denied,
expired, cancelled, failed, unknown and unavailable distinctly.

## Decisions and terminal evidence

Protected setup reviews an exact sealed plan through its existing human-controlled
surface. Helper output alone is not approval: the owning service must reload the
canonical decision, consumed approval and matching verified receipt. Unknown or
interrupted delivery is same-intent readback, not a second launch. Neither a skill
nor a model can grant credentials, host-write authority or merge permission.

`queue result` is read-only terminal retrieval, not execution, reconciliation or
renewal. A result receipt authenticates its report but cannot substitute for
missing joined evidence. The exact immutable historical policy, candidate, native
acceptance, continuity and delivery history must remain available and bound to
that report; current configuration must never replace the historical policy.
Unavailable or corrupt joins deny verified retrieval, not imply success.

Local-only/no-publish completion is narrower-target evidence, not a merged
contribution. A published PR is not protected-base merge; merge is not release,
installation or live acceptance. Source/synthetic tests are not real-provider
qualification. Final joined #379 disposition and installed-release #352 acceptance
remain separate evidence targets; no archive installation alone establishes them.
